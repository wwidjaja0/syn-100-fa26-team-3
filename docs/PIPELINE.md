# The asset pipeline

Everything in `assets/` and `ui/` is generated by the scripts in `pipeline/`. Their outputs are committed, so you only
run this when you change the room, a prop, the map, the cutting mat or the UI art. The look's rules (sizes, colours,
naming) are in [`../ASSET_GUIDE.md`](../ASSET_GUIDE.md).

`pipeline/` has a `.gdignore`, so Godot never imports it.

## Tools

| Tool | Version | Used for |
|---|---|---|
| Python 3 | 3.10+ | props, maps, mat, UI art |
| Python packages | `pip install -r pipeline/props/requirements.txt` | **trimesh 4.5.3** (pinned: newer versions drop the `world` root node that the Blender importer needs), numpy, Pillow |
| Blender | 4.2 | building the room scene and exporting it to glTF |
| Godot | 4.7.2 | importing the result |

Run every command from the repo root. Blender always runs headless (`-b`) with `--factory-startup`, so your own
Blender settings and add-ons can't change the result.

## The steps

```
                    pipeline/props/generate_assets.py ──► pipeline/props/assets/NN_name.glb
                                                                 │
 pipeline/scene/make_mat.py ──► mat_texture.png, mat_meta.json   │
 pipeline/scene/make_map.py ──► map_texture.png (video's map)    │
                                         │                       ▼
                                         │      pipeline/scene/build_pixel_scene.py (Blender)
                                         │                       │
                                         │                       ▼  climate_shelter_pixel.blend
                                         └────► pipeline/scene/build_story.py (Blender)
                                                                 │
                                                                 ▼  climate_shelter_story.blend
                                                pipeline/godot/export_glb.py (Blender)
                                                                 │
                                                                 ▼
                                               assets/shelter.glb, assets/scene_meta.json

 pipeline/scene/fetch_geo.py ──► data/world_geo.json ──► pipeline/scene/make_fiche.py ──► fiche_*.png, fiche_meta.json, globe
 pipeline/scene/pixui.py (font, icons, cursors) ─┐                                              │
 pipeline/scene/palette.json ────────────────────┴──► pipeline/godot/make_ui_assets.py ◄────────┘
                                                                 │
                                                                 ▼
                                                     ui/*, assets/palette.json
```

### 1. Props: `pipeline/props/`

```sh
python3 pipeline/props/generate_assets.py
```

- `model.py`: the `Model` class (named flat-coloured boxes, cylinders, cones, rods, rings and frames, collected
  into one trimesh scene) and `PAL`, the prop palette.
- `generate_assets.py`: one function per prop, each building a `Model`. Running it rewrites every
  `assets/NN_name.glb` and `asset_manifest.json`.

Output: 14 GLBs in `pipeline/props/assets/` (Z-up, metres, front facing -Y). Each part is its own named mesh with a
material called `mat_<part>_<n>`.

### 2. The cutting mat and the paper map: `pipeline/scene/make_mat.py`, `make_map.py`

```sh
python3 pipeline/scene/make_mat.py     # mat_texture.png + mat_meta.json (size and build grid)
python3 pipeline/scene/make_map.py     # map_texture.png etc.: the story video's PNW wall map
```

The game uses the mat. The paper map is only in the video: `build_story.py` still builds it, then `export_glb.py`
leaves it out.

### 3. The room: `pipeline/scene/build_pixel_scene.py` (Blender)

```sh
blender -b --factory-startup --python pipeline/scene/build_pixel_scene.py -- --no-render
```

Builds the cutaway room (walls, floor, sloped ceiling, pendant lamp), imports every prop GLB and places it
(`place(...)` calls), gives every material the toon look and an inverted-hull outline, adds the lights, and saves
`pipeline/scene/climate_shelter_pixel.blend`. Without `--no-render` it also renders preview stills through
`pixelize.py`.

Things to know:
- `place(stem, x, y_back=..., on_surface=...)` puts a prop against the back wall or on top of another prop.
- `EMISSIVE` picks glowing materials **by name** (`flame`, `lcd`, `lens`, `screen`, ...).
- The cabinet and shutters exist in two states each (closed/open, closed/stowed), in separate collections.

### 4. The story scene: `pipeline/scene/build_story.py` (Blender)

```sh
blender -b --factory-startup pipeline/scene/climate_shelter_pixel.blend --python pipeline/scene/build_story.py
```

This started as the builder for the story video and still makes it. The game reuses the scene it builds. It's
one long script split into six parts in `pipeline/scene/story_parts/`. `build_story.py` runs them in order in **one
shared namespace**, so a later part uses names an earlier one defined. Don't run a part on its own.

| Part | What it does | Needed by the game? |
|---|---|---|
| `story_1_setup.py` | constants, the story clock `T`, freezing the shutters/cabinet toggles, widening the room | yes |
| `story_2_props.py` | the PA speaker, paper wall map, jar, papers, cutting mat, broken radio | yes |
| `story_3_rigs_and_camera.py` | hinge empties for the shutters and cabinet (`*_hinge_L/R`), the video camera | the rigs, yes |
| `story_4_animation.py` | keys everything that moves in the video; this also fixes frame 1, the game's starting state | frame 1, yes |
| `story_5_render_setup.py` | render settings and the video's object-mask passes (`GROUPS` for Cryptomatte) | no |
| `story_6_timeline_and_save.py` | **saves `climate_shelter_story.blend`**, then the video's cursor path and timeline; `-- --render` / `--stills 1,300` render video frames | the save, yes |

### 5. Export to Godot: `pipeline/godot/export_glb.py` (Blender)

```sh
blender -b --factory-startup pipeline/scene/climate_shelter_story.blend --python pipeline/godot/export_glb.py
```

Takes the story scene at frame 1 and:
- drops the animation and the paper wall map;
- puts every interactable's meshes under a `grp_<name>` node (`GROUPS`: see "Object groups" in
  [`ARCHITECTURE.md`](ARCHITECTURE.md));
- flattens the toon node trees into plain glTF materials and records each one's colour and kind;
- bakes the outline hulls into the meshes.

It writes `assets/shelter.glb` and `assets/scene_meta.json`: groups, materials, lights, the camera rig,
`start_hidden` (parts that appear later in the story), `points` (positions the game needs, e.g. `radio_front`,
`fiche_screen`, `window`) and `craft` (from `mat_meta.json`).

### 6. The microfiche map: `pipeline/scene/fetch_geo.py`, `make_fiche.py`

```sh
python3 pipeline/scene/fetch_geo.py     # only to change map layers: downloads Natural Earth -> data/world_geo.json
python3 pipeline/scene/make_fiche.py
```

`make_fiche.py` reads `data/world_geo.json` and `data/stations.json` and draws:
- the world sheet blank and printed, each at three zoom levels;
- a 4x detail map for every area id in `stations.json`;
- a thumbnail and the idle globe texture;
- `fiche_meta.json`, which says where each lat/lon lands on each image.

Re-run it (then step 7) whenever you edit `data/stations.json`.

### 7. UI art: `pipeline/godot/make_ui_assets.py`

```sh
python3 pipeline/godot/make_ui_assets.py
```

Turns `pipeline/scene/pixui.py` (the 5x7 font `_G`, the item `ICONS`, the cursors) into `ui/pixel_font.png/.fnt`,
`ui/cursor_*.png` and `ui/icon_*.png`. It also copies the microfiche images into `ui/` and `palette.json` into `assets/`.

### 8. (Rarely) the main scene: `pipeline/godot/make_main_scene.py`

```sh
python3 pipeline/godot/make_main_scene.py
```

Writes `scenes/main.tscn` from `scene_meta.json` (lights, camera, viewports). **It overwrites any edits made in
the editor**, so only run it after moving or adding lights in Blender. Otherwise, edit `main.tscn` in Godot.

## Everything, in order

```sh
pip install -r pipeline/props/requirements.txt          # once
python3 pipeline/props/generate_assets.py
python3 pipeline/scene/make_mat.py
python3 pipeline/scene/make_map.py
blender -b --factory-startup --python pipeline/scene/build_pixel_scene.py -- --no-render
blender -b --factory-startup pipeline/scene/climate_shelter_pixel.blend --python pipeline/scene/build_story.py
blender -b --factory-startup pipeline/scene/climate_shelter_story.blend --python pipeline/godot/export_glb.py
python3 pipeline/scene/make_fiche.py
python3 pipeline/godot/make_ui_assets.py
```

You only need the steps after the one you changed, for example:
- a prop: from `generate_assets.py` on;
- the room layout: from `build_pixel_scene.py` on;
- a story prop or hinge: from `build_story.py` on;
- groups or start-hidden parts: `export_glb.py` only;
- stations: `make_fiche.py`, then `make_ui_assets.py`;
- font, icons, cursors: `make_ui_assets.py` only.

Then open Godot so it re-imports the changed files.

`.blend` files are build outputs and are git-ignored.

## Checking the result

- **Pipeline refactors** (no intended change): the output should be byte-identical. Copy `assets/shelter.glb` and
  `assets/scene_meta.json` aside, rebuild, and compare them with `cmp`. Do the same for the prop GLBs.
- **Visual changes:** run the demo walkthrough (README, "Checking a change") in both renderers and compare the
  screenshots. With `--raw` it also saves `mask.png`; its red values must be exact multiples of 12.
